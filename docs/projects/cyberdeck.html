ENGINEERING NOTES / OCTOBER 2026

Cyberdeck

A Raspberry Pi cyberdeck with a Rust interface, local control daemon, and a simulation-tested FPGA cooling controller.

ROLEIndependent hardware and systems developer
STATUSHARDWARE VALIDATED · FPGA IN SIMULATION

01 / THE PROBLEM

A small Linux device needs a responsive interface and predictable control.

The Rust UI reads status through local IPC from cyberdeckd. Thermal policy and the CoolingBackend interface separate the display from control. A SystemVerilog core combines tach capture, RPM estimation, PI control, PWM, watchdog, and sticky faults.

02 / THE SYSTEM

From input to a checked result.

Render on the deviceRust/Slint uses FemtoVG and direct LinuxKMS on the 800×480 touchscreen.
Separate status from controlVersioned read-only IPC connects the UI to a supervisory daemon.
Test the control coreSimulation covers the register map, control ticks, watchdog, and fail-safe behavior.
Preserve recoveryA software renderer and legacy UI rollback remain validated recovery paths.

Rust · Slint · LinuxKMS · SystemVerilog · Raspberry Pi

03 / EVIDENCE & LIMITS

What has been demonstrated.

Rust/Slint UI physically validated on Pi Zero 2 W at 60 FPS; touch navigation, reboot, rollback, and a 30-minute soak passed in the repository validation record.

The daemon currently uses simulated cooling. Real fan wiring, SPI framing, board pin assignments, and tuning await hardware specifications and bench measurements. The source is private; physical results quoted here come from the project validation record.
