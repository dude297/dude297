Internship Finder

A private opportunity tracker that checks eligibility, ranks fit, and keeps evidence and application state together.

ROLEIndependent full-stack developer
STATUSOWNER LOGIN REQUIRED · PUBLIC SOURCE

01 / THE PROBLEM

A listing is useful only if the eligibility and evidence are current.

Sources include verified company job boards and a curated program calendar. Ranking combines eligibility and fit, with an explanation for each score. Parsed requirements and résumé facts count only after review.

02 / THE SYSTEM

From input to a checked result.

DiscoverSync configured company boards and the opportunity feed.
Check eligibilityEvaluate the profile at the opportunity start date.
Explain fitShow score components, evidence freshness, and unknown requirements.
Track progressKeep personal application notes behind the owner session.

React · TypeScript · FastAPI · PostgreSQL · Playwright

03 / EVIDENCE & LIMITS

What has been demonstrated.

Time-aware eligibility, deterministic fit explanations, source health, freshness checks, and review-before-accept résumé facts. Hosted as an owner-only application.

This is a single-user application, not a public demo. Authentication is required to inspect private opportunities, profile data, or application history. Public source and synthetic tests are available without an account.
