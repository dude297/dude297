Modular DDR4 Memory Expansion

I have 15 mixed DDR4 laptop SO-DIMMs, each 8 GB, for about 120 GB of nominal capacity. I’m planning an open-source way to characterize and reuse them, starting with a single module.

RoleIndependent student project
StatusDesign stage

Development plan

Identify each moduleBuild a read-only I²C board to read Serial Presence Detect (SPD) data and record each module’s rank, device width, and timings.
Validate one DDR4 interfaceTrain the FPGA’s DDR4 interface for one compatible SO-DIMM, then test reads and writes across its address range.
Test a PCIe memory applianceUse a Linux driver and DMA to give a test application access to FPGA-attached memory as a device buffer.
Evaluate modular expansionTest independent channels for compatibility, throughput, and power before adding slots.

CXL Type 3 is a separate, long-term research path that depends on compatible host and endpoint hardware and IP.

I plan to publish schematics, board files, firmware, original FPGA RTL, and reproducible test results as the work progresses.

Support the first prototypes

I’m looking for 260-pin DDR4 SO-DIMM sockets, fabrication and assembly support for the SPD reader, and access to an FPGA kit with a documented DDR4 SO-DIMM interface. A few samples, a fabrication credit, or a referral to a lab or student program would help me get started.
