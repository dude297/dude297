Plasma Dynamic Wallpaper

Apple Dynamic Desktop schedules on KDE Plasma, packaged as a Python utility.

ROLEOpen-source developer
STATUSPUBLISHED PACKAGE · LINUX DESKTOP

01 / THE PROBLEM

A changing wallpaper should follow the day and survive a desktop restart.

The utility reads the image schedule from a dynamic HEIC wallpaper and applies the appropriate frame through KDE. Services keep transitions running in the background and diagnostics make configuration failures inspectable.

02 / THE SYSTEM

From input to a checked result.

Read the scheduleInspect wallpaper frames and their timing metadata.
Follow the dayUse the original timing or local solar-time alignment.
Apply across displaysUpdate KDE wallpaper state for the configured monitors.
Keep it runningUse background services, cache, and diagnostics.

Python · KDE Plasma · systemd · HEIC

03 / EVIDENCE & LIMITS

What has been demonstrated.

Published on PyPI with schedule and solar-time modes, multi-monitor support, background services, caching, and diagnostics.

The live effect requires a KDE Plasma Linux desktop and compatible wallpaper files. A browser can inspect the source, release, and recorded demonstration; it cannot validate a running desktop session.
