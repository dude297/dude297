BUILD METHOD

How I approach hard problems.

01

Model the constraint

Find the real boundary: ownership, latency, safety, power, state, or experimental validity.

02

Build the real path

Use actual systems early—real APIs, real databases, real devices, real failure modes.

03

Break it deliberately

Crash it, retry it, disconnect it, feed it adversarial state, and see what survives.

04

Make it legible

Document the architecture, boundaries, current state, and next decision so work can continue.
