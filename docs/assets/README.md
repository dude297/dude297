# Portfolio visual assets

- `ember.svg` and `ember-frames.js` are generated from the original SkillForge Ember sprite definitions (`ui/src/world/sprites.ts`), by the SkillForge team. The accompanying SkillForge license applies.
- `ember-dashboard.png` shows the October 25, 2026 Ember development dashboard. The portfolio labels it as a development preview, distinct from the public recorded demo.
- `scholarsafe.png` is a screenshot of the public ScholarSafe homepage captured October 27, 2026. Its listing and roommate example data are labeled in the original interface and portfolio caption.
- The circuit board, divider, and Cyberdeck enclosure are code-native explanatory illustrations. They are not photographs, model runs, or device telemetry.
